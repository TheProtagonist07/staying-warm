# Sprite guide: every way to make the art, and what to draw

You have an iPad, Apple Pencil and a Procreate subscription, so the main path is **drawing in Procreate**. This guide lists every method, the technical spec so your drawings drop straight into the game, and the full asset list in priority order.

Jam rule reminder: AI-generated images are prohibited, and you must have the rights to everything in the game. Drawing your own art is the safest route. Say in your submission that Claude wrote the code.

## 1. Every way to make sprites

| Method | Tools | Good for | Watch out |
|---|---|---|---|
| **Draw on iPad** | Procreate (you have it) | Characters, scenery, anything with personality | No true pixel mode: set it up as below |
| **Pixel-art apps on iPad** | Pixaki (paid), Pixel Studio, Dotpict | Real pixel grids with animation timelines | Another app to learn |
| **Pixel-art desktop** | Aseprite (paid; source available), LibreSprite (free, open source), Pixelorama (free, open source) | Animation, tilesets, exports to sprite sheets | Needs the Mac |
| **Free in the browser** | Piskel, Lospec Pixel Editor | Quick sprites, no install | Basic |
| **Illustration tools** | Krita (free, open source), GIMP (free) | Painterly backgrounds, parallax layers | Resolution discipline |
| **Level and tile maps** | Tiled (free, open source), LDtk (free) | Placing tiles into levels | Needs a finished tileset |
| **Free assets with a licence** | Kenney (CC0), OpenGameArt (filter by licence), itch.io asset packs | Filling gaps fast | Read the licence on every pack |
| **Typed in text / generated by code** | What I made | Placeholders, tests, effects like glows and fog | Counts as AI-made, so not for the submission |
| **Hybrid** | You draw the key shapes, I script the rest | Recolours, tilesets from one drawing, sheet packing | Best value |

**Recommendation:** Procreate for everything with character (fox, friends, enemies, trees, props), plus code-made effects for light, fog and particles (those are maths, not drawings). Use the free options only for small gaps and always keep the licence page.

## 2. Procreate setup

Procreate is a smooth-brush painting app, so a few settings matter.

1. **Small canvas.** Draw at the real size, never big and shrink. Suggested:
   - Characters: **32 x 32** (the fox is 16 x 19 today; 32 gives room to draw)
   - Tiles: **16 x 16** (the world is built from 16px tiles)
   - Props: **16 x 16 to 32 x 32**
   - Big scenery (trees, ruins): **64 x 96**
2. **Turn on a grid.** Canvas > Drawing Guide > Edit Drawing Guide > Grid, set the grid to **1 px** if you can, or 4 px for orientation.
3. **Use a hard pixel brush.** Use the "Pixel" brush set (or any brush with Streamline and Stabilisation at 0, size 1 px, no softness). Turn off Apple Pencil pressure curves for size so lines are even.
4. **Keep colours flat.** No gradients, no soft shadows, no blur. Use 4 to 6 colours per sprite: base, shade, light, accent, outline. Use Lock Alpha when recolouring.
5. **One palette for everything.** Make a Procreate palette from the colours in `sprites/defs/palette.ts` (or pick your own and send me the hex codes so the game's lighting matches).
6. **Animate with Animation Assist.** Actions > Canvas > Animation Assist. Use one layer per frame, 8 to 12 fps, onion skin on.
7. **Export each frame.** Procreate has no sprite-sheet export. Export animations as PNG frames (hide other layers, or Share each layer) and put them in one folder named like `fox-run-1.png`, `fox-run-2.png`. I'll pack them into sheets with a script.
   - I have not tested this against your version of Procreate. If frame export differs, send me one test export and I'll adapt.
8. **Resampling.** If you ever scale, scale by whole numbers (2x, 3x) with nearest-neighbour so pixels stay sharp. Never scale by 1.5x.
9. **Transparent background**, PNG, no compression artefacts.

## 3. Rules so the art fits the game

- **Facing:** draw everything facing **right**. The game mirrors for left.
- **Outline:** none on most sprites, a 1px darker colour on characters so they separate from the dark world.
- **Light direction:** from the top-left (the moon).
- **Danger colour:** purple for enemies and cold things, warm orange for friends and warmth. Never make a harmless object purple.
- **Readability:** the player and anything you can touch must be the brightest or highest-contrast shapes on screen. Decoration stays dim.
- **Anchor:** characters stand on the bottom edge of their canvas. Leave one empty row at the top for the jump stretch.
- **Naming:** `thing-state-frame.png`, lowercase, dashes. e.g. `fox-run-3.png`, `lantern-lit-1.png`.
